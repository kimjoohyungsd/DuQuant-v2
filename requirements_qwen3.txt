# requirements_qwen3.txt
#
# Dedicated environment for Qwen3 runs (scripts/torq/run_torq_Qwen3.sh,
# scripts/env_utils.py's Qwen-path scripts). This repo's shared `flatquant`
# conda env pins a transformers version that doesn't resolve the Qwen3
# architecture (`transformers.models.qwen3`), so Qwen3 model loading needs a
# python whose installed transformers actually supports it -- either this
# dedicated env, or the .vendor/transformers_qwen3 PYTHONPATH fallback (see
# .vendor/README.md). This file is for the former:
#
#   conda create -n duquant-qwen3 python=3.10 -y
#   conda activate duquant-qwen3
#   pip install -r requirements_qwen3.txt
#   QWEN3_PYTHON=$(conda run -n duquant-qwen3 which python) \
#       bash scripts/torq/run_torq_Qwen3.sh
#
# Everything below matches requirements.txt except the core package versions
# ── [동시 업데이트 필수 코어 패키지] ── swapped for ones that actually resolve
